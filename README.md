# GUESSING APP

## Use cases:

- UC1: Game Initialization, Printed the Game rules and instructions.
- UC2: User Guess Submission, Used Scanner to input the number.
- UC3: Hint Generation, Used method abstraction and encapsulation of hint logic.
- UC4: Error Handling and validation of the GuessingApp.
- UC5: Storing Game Result Storage (File / Database) in .txt file.
- UC6: Game Restart & Exit.
